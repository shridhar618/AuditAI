# AuditAI Documentation

This directory contains documentation for the AuditAI project.

## Documentation

- [Roadmap](roadmap.md) - Detailed roadmap for the AuditAI project.

## Project Overview

AuditAI is a deloitte capstone project that aims to build an AI-powered audit assistant.

## Subsystems

1. Data & ingestion
2. Regulation RAG agent
3. Control-testing agent (deterministic rules)
4. ML anomaly detection agent
5. Orchestration (LangGraph)
6. Review dashboard (React)
7. Validation & metrics
8. Security & deployment

For more details, see the [roadmap](roadmap.md).
